Cleanup review:

  dd -> add the selected exact path to the cleanup basket.
       The right pane shows the preliminary scan separately from the
       coding agent's metadata-only advice. The advice is not authorization.
  Y  -> open a dialog showing the exact path and size.
  y  -> confirm inside that dialog and move the path to system Trash.
  u  -> restore the most recent Trash move without overwriting a newer path.

Path actions and workspaces:

  t  -> open Terminal at the selected folder.
  v  -> open VS Code, c -> open Cursor, o -> reveal in Finder.
  m  -> save or remove a bookmark; M -> browse bookmarks and recent paths.
  w  -> save the current path and scope; W -> restore the last workspace.
  D  -> run a bounded metadata-only relationship analysis for the selected path.
       It can connect project markers, source, dependencies, build folders,
       outputs, and possible same-name/same-size matches.
  C  -> copy the metadata-only question context.

Advanced browsing:

  /  -> fuzzy-search the loaded tree. Search matches names, paths, areas,
       categories, and local tags; Enter applies and Esc cancels.
  f  -> choose a filter such as files only, large items, rebuildable, or tagged.
  s  -> choose a sibling sort order such as name, size, or newest first.
  T  -> edit tags for the selected local path. Enter saves; Esc cancels.
  N  -> open the selected folder in a new session-local tab.
  gt -> next tab; gT -> previous tab; X -> close the current tab.

  Mouse click -> select. Double-click a folder -> open it. Scroll wheel -> move.
