Configure AI

The explorer works without AI. Clean Your Data writes a metadata-only prompt to stdin and reads the answer from stdout. No shell is used. Custom-command arguments are saved verbatim, so never put credentials in them. A custom command still has its own operating-system permissions; configure only one you trust.

For hosted providers, put the API key in that tool's environment or credential store. Do not paste a secret into this command.
This session is controlled by CLEAN_YOUR_DATA_AI_COMMAND. Restart without that environment variable to edit the saved provider here.

Keyboard

Mouse and keyboard operate the same selection and state as the terminal explorer.

j / k or ↑ / ↓ — move selection Enter — open or close folder A — ask the configured Agent dd — add or remove exact path from cleanup basket u — undo the latest Trash move gg / G — first or last visible row / — search Esc — close dialogs or leave input
